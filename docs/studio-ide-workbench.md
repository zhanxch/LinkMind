# IDE 工作台

进入具身模式后，左侧活动栏和项目树、上方标签内容区、下方原生 Agent 对话、底部状态栏构成一个工作台。模型选择、权限、附件、发送和运行中的插话继续由 DSH 负责。

项目根节点对应真实工作区。右键项目或分类文件夹新建会话，工作区由右键位置确定；分类目录不成为磁盘目录或 Agent 父子关系。顶部新建操作使用左侧当前选中的位置，位置提示始终显示目标。搜索跳转会话后，创建位置跟随该会话。

上方通过原生标签浏览项目文件、其他会话、真实控制会话、相机画面、概览及任务图。打开参考会话不切换下方对话；需要接续时显式切换。终端入口打开原生终端标签，不替换下方对话。

项目概览读取最近六次运行的耗时与 `result.native.score`。缺失分数保持空态，程序退出不代表任务成功；单次分数不作为成功率估计。快照来源和历史状态始终标注，运行中按新帧更新。不同环境与预算的记录不能直接作为方法优劣的证据。

任务图读取同一项目的工作项和已记录的 `depends_on`。只对真实依赖画连线，不自动添加“数据→训练→评估”的固定流程；选择不同任务可回看其工作项。任务说明、证据和跨会话接续仍在原有任务面板中。

拖动横向分界线调整对话高度，纵向分界线调整目录宽度；分界线也支持方向键和 Home。窄窗口采用单列内容与项目抽屉。顶部搜索只过滤会话和视图；文件全文搜索仍用原生文件查看器。

实现边界：新增的 shell 和 overview 模块负责展示；原生 DSH 继续持有会话、认证、模型、资源与标签状态。当前不是完整 VS Code 编辑器，也不包含任意训练文件自动绘图。外部 HexaShell 会话读取 JSONL，插话需要相应方案提供输入适配。
