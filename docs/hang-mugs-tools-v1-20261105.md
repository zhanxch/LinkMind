## 改动

只为 hang_mugs 开放现有隔离 Python cells 和实测关节保持式夹爪/等待，并增加 `robo.move_feature`。模型给出当前可见特征点、目的地和目标姿态，工具按刚性抓持假设计算特征到 TCP 的偏移，在每个短段采样中补偿该偏移；所有目标仍经过原 `execute_chunk` 验证、编译、计划要求和控制步预算。预测误差不是持物或任务成功反馈，接触或滑落后需基于当前图像重新定位。

可选 `measure_mug_geometry` / `robo.measure` 只接收当前公开 RGB 和配对标定：表面点、极线匹配提示、挂钩端点/轴/半径、平面杯柄内边界测量。模型自行选择像素与对应关系；几何只读、0 控制步，没有仿真、深度、奖励、物体真值或动作能力。直接复用冻结 HexaShell 的 precision/pegs 只读函数，并将两个依赖纳入来源哈希。没有导入其自动抓取、插入或悬挂程序，也没有测量准入或阶段调度。

持久 cell 与机器人原语设计参考 PyRUA-Lean `e8f01dc`；几何来源为 HexaShell `d1a2a24`，原 Apache-2.0 仓库及授权文件保留。原完整 TRAIN、按需检索、模型自己的 `record_plan`、原生 hang delta/IK、800 步上限和评分不变。吐司的 0.25rad 检查没有扩到挂杯。任务提示补充当前抓法、杯柄/TCP 区别与短动作反馈，没有布局坐标、尺寸或固定全任务脚本。
